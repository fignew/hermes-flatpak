> **This is NOT an official Nous Research product. This repo is unofficial, not

Unofficial flatpak packaging of [Hermes Desktop](https://github.com/NousResearch/hermes-agent)
(`dev.nousresearch.hermes`), rebuilt daily from upstream `main`, plus release builds
matching upstream's tagged releases.

## Install

### Option A — add this repo as a flatpak repo (recommended)

The CI publishes a real flatpak repository (both arches + metadata), so you can
add it once and get `flatpak update` support for good.

Nightly channel (rebuilt daily from upstream `main`):

```sh
flatpak --user remote-add \
  --if-not-exists hermes-nightly \
  https://fignew.github.io/hermes-flatpak/nightly.flatpakrepo
flatpak install --user hermes-nightly dev.nousresearch.hermes
```

Then run it like any other desktop app or:

```sh
flatpak run dev.nousresearch.hermes
hermes-desktop   # CLI alias also available inside the sandbox
```

Updates come to you with `flatpak update --user` (or automatically with your
desktop's flatpak update integration).

> The `nightly.flatpakrepo` file is auto-generated by the nightly workflow
> (runs daily at 04:37 UTC). If GitHub Pages has not finished publishing yet
> on a fresh repo, wait a minute or run a "Flatpak Nightly Build" manually
> from the Actions tab first.

### Option B — single-file bundle (no repo)

Grab `Hermes-<ver>-x86_64.flatpak` (or `-aarch64`) from the
[latest nightly](https://github.com/fignew/hermes-flatpak/releases/tag/nightly),
then:

```sh
flatpak install --user ./Hermes-0.21.3-x86_64.flatpak
```

## What's inside

- Hermes Agent backend pre-bundled at `/app/lib/hermes-agent` with a
  fully-synced Python venv, so first run needs no network install.
- Bundled git 2.55.0, ripgrep 14.1.1 (x86_64 only), cua-driver 0.23.2
  (x86_64 only — computer-use on Wayland via the libei/portal stack).
- Minimal flatpak sandbox:
  `network`, `wayland`+`x11`, `pulseaudio`, `dri`, `xdg-download`,
  `org.freedesktop.Notifications`, `org.a11y.Bus`, and
  **deliberately no `--filesystem=home`** — everything else goes through
  portals. Your agent's state lives under `~/.var/app/dev.nousresearch.hermes/`.

## CI

| Workflow | What it does |
|---|---|
| **Flatpak Nightly Build** | Daily at 04:37 UTC: resolves `main` to its newest commit, builds both arches, smoke-tests, overwrites the rolling `nightly` release |
| **Flatpak Release Build** | Builds a specific upstream tag (`workflow_dispatch` with `tag=vX.Y.Z`) |
| **Upstream Release Watch** | Hourly: if a new upstream release tag appears, auto-dispatches Flatpak Release Build |

Smoke tests: after each build the bundle is installed and `hermes --version`,
`rg --version`, `git --version` are probed inside the sandbox.

## Caveats / known issues

- **Unofficial** — package not examined by Nous Research; report packaging bugs
  in this repo's issues, not upstream.
- **WIP** — things break; if tonight's nightly is bad, yesterday's artifact is
  still on the [Actions runs page](https://github.com/fignew/hermes-flatpak/actions).
- **Flathub** — Hermes is not on Flathub; this manifest is Flathub-shaped but
  a real Flathub submission requires maintainer sign-off from Nous Research.
- **ARM64** works but bundle installs expect a real aarch64 host (no cross-arch
  install on x64 machines).

## Rebuilding locally

```sh
# Optional: pick a specific ref; default main
export HERMES_REF=main
python3 packaging/generate-manifest.py         # expands __HERMES_REF__ placeholder
flatpak-builder --force-clean --disable-rofiles-fuse \
  --repo=repo _build packaging/dev.nousresearch.hermes.yml
flatpak build-bundle repo Hermes-x86_64.flatpak dev.nousresearch.hermes master \
  --runtime-repo=https://flathub.org/repo/flathub.flatpakrepo
```
